MUSHINDI GOLD SCALPER — Android installable web-app prototype

WHAT IT DOES
- Mobile-first XAUUSD chart-reading planner.
- Manual decision recording.
- Automatic decision simulation (NOT broker execution).
- Cash-risk budget calculator.
- Local practice journal and CSV export.
- Can be installed from a secure HTTPS host as a Progressive Web App (PWA).

IMPORTANT LIMITATIONS
- This is not a signed Android APK.
- It has no live market data feed and no FXPesa connection.
- It cannot send demo or live orders.
- Automatic mode only simulates and records decisions.
- It does not calculate lot size because broker contract/tick-value details must be verified.
- Do not enter broker passwords or API secrets.

ANDROID INSTALL
1. Upload the contents of this folder to a secure HTTPS static host you control.
2. Open the hosted index.html URL in Chrome on Android.
3. Open Chrome menu (three dots) and choose Install app or Add to Home screen.
4. Launch MUSHINDI GOLD SCALPER from your home screen.

LIVE TRADING RELEASE GATE
Do not connect a live account until FXPesa has confirmed in writing an approved API/EA and hosting method, and the software has passed demo forward-testing, risk sizing, spread/slippage, reconnect and security tests.
